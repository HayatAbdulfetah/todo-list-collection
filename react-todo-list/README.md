# React + TypeScript Todo List

A beautifully designed, interactive Todo List application built with React, TypeScript, and CSS. This project features a modern glassmorphism user interface set against a high-quality background, prioritizing clean aesthetics and high visibility.

## Features

- **CRUD Operations:** Easily add new tasks, edit existing ones, and delete tasks you no longer need.
- **Data Persistence:** Tasks are automatically saved to the browser's LocalStorage, ensuring data is not lost upon page refresh.
- **Glassmorphism UI:** A sleek, frosted-glass design that perfectly complements the background imagery.
- **Bold Typography:** Enhanced readability across all inputs, buttons, and task items.
- **React Icons:** Clean, modern iconography for action buttons (Edit, Delete, Save).

## Technologies Used

- React (with Hooks: `useState`, `useEffect`)
- TypeScript
- Vite
- CSS3 (Custom properties, backdrop-filter, flexbox)
- React Icons

## How to Run Locally

1. Clone this repository to your local machine.
2. Navigate into the project directory using your terminal.
3. Install the required project dependencies by running:
   `npm install`
4. Start the Vite development server by running:
   `npm run dev`
5. Open your web browser and visit the local host link provided in your terminal (usually `http://localhost:5173`).
